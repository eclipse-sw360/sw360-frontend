# SW360 Frontend — Playwright UI Tests

End-to-end UI tests for the SW360 Frontend, powered by [Playwright](https://playwright.dev/).
Tests live in [`tests/e2e/`](./e2e) and are organized by application module.

---

## Prerequisites

- **Node.js** and **pnpm** installed
- A running **SW360 Frontend** (default `http://localhost:3000`) and **backend API** (default `http://localhost:8080`).
  - In headless mode, the frontend dev server starts automatically if it is not already running.
  - For **UI mode** (`--ui`), start the dev server yourself first with `pnpm dev`.

---

## Setup

```bash
# 1. Install dependencies (if not already)
pnpm install

# 2. Install the Playwright browser (Chromium)
npx playwright install chromium

# 3. Configure your local environment
# Add .env.local under ./tests and set SW360_BASE_URL, SW360_API_URL, credentials, etc.
```

## Environment variables

Configuration is read from [`tests/.env.local`](./.env.local) (loaded by
[`playwright.config.ts`](../playwright.config.ts)) and can be overridden by shell env vars.
Defaults are defined in [`tests/config.ts`](./config.ts).

| Variable                    | Description                          | Default                  |
| --------------------------- | ------------------------------------ | ------------------------ |
| `SW360_BASE_URL`            | Frontend URL under test              | `http://localhost:3000`  |
| `SW360_API_URL`             | Backend REST API URL                 | `http://localhost:8080`  |
| `SW360_TEST_ADMIN_EMAIL`    | Admin user email for login           | `setup@sw360.org`        |
| `SW360_TEST_ADMIN_PASSWORD` | Admin user password                  | `12345`                  |
| `COUCHDB_URL`               | CouchDB URL (test data setup)        | `http://localhost:5984`  |
| `COUCHDB_USERNAME`          | CouchDB username                     | `admin` (`sw360` in CI)  |
| `COUCHDB_PASSWORD`          | CouchDB password                     | `12345` (CI differs)     |


> **Note:** `tests/.env.local` may contain credentials — do not commit real secrets.

## Running tests

All commands use the `test:pw*` scripts defined in [`package.json`](../package.json),
which wrap `npx playwright test`.

### Run everything (headless)

```bash
pnpm test:pw tests/e2e/ --project=chromium
```

### Run specific modules

```bash
pnpm test:pw tests/e2e/projects/ --project=chromium
pnpm test:pw tests/e2e/components/ --project=chromium
pnpm test:pw tests/e2e/licenses/ --project=chromium
pnpm test:pw tests/e2e/packages/ --project=chromium
pnpm test:pw tests/e2e/vulnerabilities/ --project=chromium
pnpm test:pw tests/e2e/search/ --project=chromium
pnpm test:pw tests/e2e/home/ --project=chromium
pnpm test:pw tests/e2e/admin/ --project=chromium
pnpm test:pw tests/e2e/accessControl/ --project=chromium
pnpm test:pw tests/e2e/ecc/ --project=chromium
pnpm test:pw tests/e2e/preferences/ --project=chromium
pnpm test:pw tests/e2e/requests/ --project=chromium
```

### Run a single test file

```bash
pnpm test:pw tests/e2e/projects/projectList.test.ts --project=chromium
```

### Interactive UI mode

Start the dev server first, then launch the Playwright UI:

```bash
pnpm dev            # in one terminal
pnpm test:pw:ui     # in another
```

### Headed mode (visible browser)

```bash
pnpm test:pw:headed tests/e2e/projects/
```

### Debug mode

Step through a test with the Playwright Inspector:

```bash
pnpm test:pw:debug tests/e2e/projects/projectList.test.ts
```

### Codegen (record a new test)

```bash
pnpm test:pw:codegen
```

### Test structure

```
tests/
├── .auth/              # Saved auth storage states (generated by setup)
├── .env.local          # Local environment configuration (template)
├── config.ts           # Central test config + default credentials
├── global-setup.ts     # Role-based setup (only when ENABLE_ROLE_TESTS=true)
├── global-teardown.ts  # Role-based teardown
├── reports/            # HTML report output
├── results/            # Test artifacts (traces, screenshots, videos)
└── e2e/
    ├── auth.setup.ts   # Authentication setup (runs once before all tests)
    ├── accessControl/
    ├── admin/
    ├── components/
    ├── ecc/
    ├── helpers/
    ├── home/
    ├── licenses/
    ├── packages/
    ├── preferences/
    ├── projects/
    ├── requests/
    ├── search/
    └── vulnerabilities/
```

## Reports & Artifacts

- **HTML report:** written to `tests/reports/`. Open the latest run with:

  ```bash
  npx playwright show-report tests/reports
  ```

- **Traces, screenshots, videos:** captured on failure/first retry and stored in `tests/results/`.
  - `trace: on-first-retry`
  - `screenshot: only-on-failure`
  - `video: on-first-retry`
